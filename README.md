# Fire-ants-in-the-Brazilian-Atlantic-Forest

DATA FROM: Fire ants in the Brazilian Atlantic Forest: history of occurrence and its implications


All the data obtained from the collections and data from the Atlantic ants database were cataloged in the database named: “Solenopsis_database”.


To compare the decades, the data was organized into data frames: 

S. invicta = decada_invicta
S. saevissima = decada_saevissima

The script used to run the analysis in R for figure 4 is named "figure 4"

The data from the variables extracted from mapbiomas with the values for the number and area of native vegetation/anthropic fragments were inserted together with the occurrence number of each species in the following dataframes: 

S. invicta = “data_invicta_atual”
S. saevissima = “dados_saevissima_atual”


The script used to run the analysis in R for figures 5 and 6 is named “figure 5 and 6”
